Shinkai City — 单文件演示版
==========================

这是一个自包含的网页：HTML、样式、全部 JS（含 three.js）、角色立绘都打包在
index.html 这一个文件里。没有服务器、没有 npm、没有联网需求。

怎么用
------
方式一（推荐）：双击 start-demo.bat。它会找本机或同目录的 Chrome/Edge，用
"允许读取本地文件" 的方式打开 index.html，顺带屏蔽自动播放限制。

方式二：直接把 index.html 拖进 Chrome / Edge 窗口，或用右键 "打开方式"。
（Chrome 打开本地文件时，某些版本会把 file:// 的资源读取卡得很严，
 start-demo.bat 加了 --allow-file-access-from-files，可以绕开这类边角问题。）

想连浏览器一起带走：把绿色版 Chrome 的文件夹改名成 chrome，和 index.html 放
在同一层，start-demo.bat 会优先用它 —— 这样目标设备装的是什么浏览器都不重要。

进去之后：首次会看到 "正在建造城市" 的加载条，约 1~3 秒进 17:35 的黄昏街道
（太阳还在地平线上，是一天里最好看的一段）。城市时间会自动往前走，
约 35 秒后天黑，之后就一直是夜景灯火。

操作
----
W A S D   走路          Shift    跑
拖动鼠标  环视           滚轮     远近
E         和身边的人交谈   1 2 3    选择对话选项
V         俯瞰全城        M        城市地图 / 点击传送
[ ]       把时间往前/后调 20 分钟（想立刻看夜景就多按几次 ]）

验收要点（10 秒内可确认它活着）
------------------------------
· 左下角显示 fps，应在 55~72 之间（视显示器刷新率与显卡）
· 按 M 打开地图，点任意名字可以传送过去
· 按 V 拉高到城市上空，再按 V 回到街上
· 找街上的人按 E，会弹出对话框；选完选项后左下角会出现流言
  （"铃 → 青：你对人说话很温和" 这种，说明这次对话被传出去了）

配置低的机器
------------
在地址栏的路径后面加 ?quality=lite 再回车，例如：
  file:///E:/Shinkai-City/dist/index.html?quality=lite
行人从 520 降到 210、车辆从 260 降到 110，帧数会明显回升。

如果打不开
----------
· 黑屏但 HUD 正常：显卡/浏览器不支持 WebGL2，换 Chrome 或 Edge。
· 提示 "启动失败：xxx"：那就是真的报错了，把这段文字记下来。
· 用 IE / 很旧的 Edge：不支持，请换新版浏览器。
